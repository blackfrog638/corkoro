# Obsidian 发布入口

预留插件位置，当前无 manifest 或可安装插件。

负责收集配置、展示扫描候选、让用户选择文章、预览构建计划和展示结果。选择操作通过 CLI 修改 Vault 内单配置的 publication.entries，并保留 site/theme 等区块，不要求修改源笔记属性。桌面端调用独立 CLI，不捆绑 Astro 构建工具，不重复实现内容依赖分析和转换规则。

启动 CLI 时使用可执行文件与参数数组；配置路径、版本兼容性、未保存笔记处理和错误展示在插件阶段明确。先验证 CLI 发布链路，再实现插件；移动端远程构建另行设计，不能假设手机能运行本地 CLI。
