# 0013：本地预览固定已提交版本

日期：2026-11-14。

preview --out-dir <目录> [--port <端口>] [--json] 消费明确的构建输出根目录，不读取当前 Vault 配置、不触发构建。参数目录相对调用目录，默认端口 4321，端口 0 由系统分配；首版固定监听 127.0.0.1。

启动时 readSite 校验活动指针与所有文件摘要，再逐一读取并复核摘要，将该版本文件保存在内存。HTTP 请求仅查找该文件映射，不把请求路径用于文件系统读取。这样后续重建、文件替换或加入文件不会扩大可访问范围；代价是内存与站点体积成正比，首版面向本地博客而非生产托管。重建后需要重启预览。

挂载路径来自该版本内容包的 site.address.base，而不是当前配置或生产 origin。只接受 GET/HEAD，不列目录；无匹配文件返回 404，非法编码返回 400，其它方法返回 405。输出根、生成项目和旧版本不会被提供。缓存禁用，类型不可嗅探。

JSON 启动结果使用统一 envelope，data 为 url/buildId，effect=none、configVersion=null。启动成功是长运行命令的就绪信号，不代表进程结束或远端部署；启动失败使用现有退出码，SIGINT/SIGTERM 停止服务。preview 不属于七命令有限模型的证明范围。
