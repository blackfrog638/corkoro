# 本地命令封装与配置事务终态

日期：2026-11-12。状态：实现约束，尚无运行时实现；细化 0005。

## 决策

- 七个本地命令固定输入分支、JSON data、effect/configVersion 和错误优先级，详见 [结果协议](../cli-protocol.md)。plan 差异首版固定为 null，避免依赖尚未定义的构建 manifest。
- 配置写锁基于规范路径槽位和稳定载体；不能锁会被原子替换的配置 inode。锁忙立即退出，不等待或自动重试。
- 适配层需提供进程退出释放的 OS 互斥与原子提交；不支持就拒绝，不能退化为时间戳锁或先删后写。
- 取消在提交前返回 130；提交进行中先判定结果；已提交不回滚，无法确定时返回 5/effect=unknown。
- .corkoro-state 是排除公开的事务元数据，锁载体保留；旧临时文件不自动重放或删除。详细恢复边界见 [事务协议](../config-transactions.md)。
