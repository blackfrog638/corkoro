# 发布核心

预留独立内容处理与发布流程模块，当前无实现。

不得依赖 Obsidian API 或 UI。配置和源文件由外部传入，读取、输出与远端传输通过适配边界接入。CLI 调用核心，桌面插件调用 CLI。

内部区分扫描、显式选择、规划和执行；构建不部署、不发信。第一阶段实现扫描、单配置初始化、内联清单管理及配置/路径/选择检查，第二阶段补全依赖解释与公开内容包导出。扫描线索和引用关系不能扩大配置内文章清单、站点页及显式资料的授权。init/content 仅创建或修改指定配置，保留其它区块；其余本地处理只读输入，站点产物输出到 Vault 外。不提前搭建通用任务调度器或持久化执行计划。
