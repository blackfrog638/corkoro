# 内容格式

预留统一配置（含发布清单、site、theme）、输出内容包与诊断的运行时校验模块，当前没有代码。首版输入语义见 [发布范围协议](../../docs/publication.md)，命令输出见 [CLI 契约](../../docs/cli.md)。

配置描述源目录、语法、附件范围、内联 publication.entries、site、theme 及输出；文件路径以配置目录为基准。配置内清单保存文章 source、ID、slug 和 publish；文章 source 相对源根目录。site 保存资料、友链及页面引用；页面 ID 与文章 ID 全局唯一。输出内容包只记录实际公开文件，不能回写覆盖输入清单。

协议应规定公开范围、支持语法、改名与撤回行为。格式修改需同时验证 CLI、导出方和网站消费方，不能泄露源机器的绝对路径或密钥。
